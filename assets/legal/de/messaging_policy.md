# Nachrichtenrichtlinie

**Version:** 1.0.0

**Inkrafttreten:** 5. Oktober 2026

# 1. Umfang

Nachrichten dienen den Teilnehmern einer Veranstaltung, um sich über diese Veranstaltung auszutauschen. Support-Anfragen nutzen einen eigenen Kanal.

# 2. Regeln

Belästigung, Drohungen, Spam, Betrug und rechtswidrige Inhalte sind verboten. Fordere keine Bestätigungscodes, Passwörter oder Kartendaten an und teile sie nicht.

# 3. Sichtbarkeit

Veranstaltungsnachrichten werden Nutzern gezeigt, die in dieser Veranstaltung kommunizieren dürfen. Support-Nachrichten sehen die Personen, die den Support bearbeiten.

# 4. Sperren und Beschwerden

Du kannst einen Nutzer sperren und eine Nachricht melden. Die Prüfung kann Inhalte entfernen oder ein Konto einschränken.

# 5. Löschung

Wenn dein Konto gelöscht wird, wird dein Profil gelöscht. Nachrichten, die im Veranstaltungs-Chat eines anderen Nutzers bleiben, können erhalten bleiben, damit dieser Chat fortgesetzt werden kann.
